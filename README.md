# ns-3 Course Lab Repository

This repository holds the course lab materials for ns-3 networking experiments.

## Repository structure

- `labs/poisson/` — Poisson traffic lab
- `labs/poisson/markov/` — Markov chain experiments
- `deps/ns-3-dev/` — upstream ns-3 source (added as a submodule or dependency)

## Setup

Follow the instructions in `labs/poisson/STUDENT-SETUP-WSL2.md`.
