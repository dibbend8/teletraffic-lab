# Packet-based ns-3 simulations

This folder contains the realistic packet-level examples that use:

- nodes
- IP addresses
- sockets
- links and channels
- packet generation and handling
- callbacks and pcap traces

The main example is the Poisson arrival demo under `labs/poisson/`.

These are different from the event-only examples in `labs/events/` because they model actual packet flow over a network.
